Guía Completa de Etiquetas HTML

Esta guía combina todas las partes para explorar las etiquetas HTML más comunes, desde la estructura básica y metadatos hasta contenido de texto, multimedia, tablas, formularios y las etiquetas semánticas de HTML5. Expande cada sección para ver la función de la etiqueta, un ejemplo de código y su salida en vivo.

Parte 1: Etiquetas de Estructura Básica del Documento y Metadatos

<!DOCTYPE html>

Función: Es una declaración que define el tipo de documento y la versión de HTML (HTML5 en este caso). No es una etiqueta HTML, sino una instrucción para el navegador que debe ser la primera línea de cualquier documento HTML.

Código:

<!DOCTYPE html>

Salida en vivo:

No tiene una salida visual directa en el cuerpo de la página, pero es esencial para que el navegador renderice el HTML correctamente en "modo estándares".

<html>

Función: El elemento raíz de una página HTML. Es el contenedor para todo el contenido y las etiquetas HTML en el documento.

Código:

<html lang="es">
  <!-- Aquí va todo el contenido de la página -->
</html>

Salida en vivo:

Contiene toda la estructura que estás viendo en esta página. No tiene una representación visual directa en sí misma, sino que define el contexto del documento.

<head>

Función: Contiene metadatos sobre el documento HTML, como el título de la página, enlaces a hojas de estilo CSS, scripts JavaScript, configuraciones de caracteres, etc. Su contenido NO es visible directamente en el cuerpo de la página.

Código:

<head>
  <meta charset="UTF-8">
  <title>Mi Título de Página</title>
  <link rel="stylesheet" href="styles.css">
</head>

Salida en vivo:

El contenido de <head> no se renderiza directamente en el cuerpo visible de la página.

<meta>

Función: Define metadatos sobre el documento HTML que no pueden ser definidos por otras etiquetas meta específicas. Se utiliza para especificar la codificación de caracteres, la descripción de la página, palabras clave, configuración del viewport para responsividad, y más.

Código (ejemplos comunes):

<meta charset="UTF-8">
<meta name="description" content="Una descripción de mi página web.">
<meta name="viewport" content="width=device-width, initial-scale=1.0">

Salida en vivo:

Las etiquetas <meta> proporcionan información al navegador y a los motores de búsqueda, pero no tienen una salida visual directa en la página.

<title>

Función: Define el título del documento HTML. Este título aparece en la barra de título del navegador, en la pestaña de la ventana o como título de un marcador/favorito.

Código:

<title>Título de mi Documento</title>

Salida en vivo:

El título de esta misma página, "Guía Completa de Etiquetas HTML", se define con la etiqueta <title> en la sección <head>.

<link>

Función: Se utiliza para establecer un vínculo entre el documento HTML y un recurso externo. Su uso más común es para vincular hojas de estilo CSS externas (<link rel="stylesheet" href="styles.css">) o iconos de favoritos (favicons).

Código (ejemplos comunes):

<link rel="stylesheet" href="mi-estilo.css">
<link rel="icon" href="favicon.ico" type="image/x-icon">

Salida en vivo:

<link> no tiene una representación visual directa, pero es crucial para cargar los estilos y el icono que ves en la pestaña del navegador.

<style>

Función: Permite incrustar código CSS directamente dentro del documento HTML. Esto se usa comúnmente en la sección <head> para estilos específicos de una página, o en el <body> para estilos de alcance limitado.

Código:

<style>
  p {
    color: blue;
    font-size: 16px;
  }
</style>

Salida en vivo:

Este párrafo tiene estilos aplicados directamente desde una etiqueta <style> interna.

<base>

Función: Especifica una URL base o un objetivo base para todas las URL relativas en el documento. Solo puede haber una etiqueta <base> en un documento.

Código:

<head>
  <base href="https://ejemplo.com/imagenes/" target="_blank">
</head>
<body>
  <img src="mi-imagen.png"> <!-- Esto se resolverá como https://ejemplo.com/imagenes/mi-imagen.png -->
</body>

Salida en vivo:

La etiqueta <base> no tiene una salida visual directa, ya que afecta cómo el navegador resuelve las URLs relativas en el fondo.

<body>

Función: Contiene todo el contenido visible de la página web, como texto, imágenes, videos, enlaces, formularios, etc. Es donde reside la mayor parte del HTML que interactúa con el usuario.

Código:

<body>
  <h1>Bienvenido a mi Web</h1>
  <p>Este es el contenido principal de la página.</p>
</body>

Salida en vivo:

Todo este texto que lees está dentro de <body>

Incluyendo esta explicación y los ejemplos que ves.

Parte 2: Etiquetas de Contenido de Texto

<h1> a <h6>

Función: Definen encabezados de sección. <h1> es el más importante (generalmente para el título principal de la página o sección) y <h6> es el menos importante. Ayudan a los navegadores y a los motores de búsqueda a comprender la estructura del contenido.

Código:

<h1>Título Principal</h1>
<h2>Subtítulo de Sección</h2>
<h3>Encabezado de Subsección</h3>
<h4>Encabezado de Nivel 4</h4>
<h5>Encabezado de Nivel 5</h5>
<h6>Encabezado de Nivel 6</h6>

Salida en vivo:

Este es un Encabezado H1

Este es un Encabezado H2

Este es un Encabezado H3

Este es un Encabezado H4

Este es un Encabezado H5
Este es un Encabezado H6
<p>

Función: Define un párrafo de texto. Es la etiqueta más fundamental para bloques de texto en un documento HTML.

Código:

<p>Este es un ejemplo de un párrafo de texto.</p>
<p>Cada etiqueta p crea un nuevo bloque de texto.</p>

Salida en vivo:

Este es un ejemplo de un párrafo de texto.

Cada etiqueta p crea un nuevo bloque de texto.

<a>

Función: Define un hipervínculo (enlace). Se utiliza para conectar a otra página web, a un archivo descargable, a una dirección de correo electrónico, o a una sección dentro de la misma página. El atributo href es obligatorio y especifica el destino del enlace.

Código:

<a href="https://www.google.com">Ir a Google</a>
<br>
<a href="#seccion-abajo">Ir a una sección</a>
<br>
<a href="mailto:ejemplo@dominio.com">Enviar Correo</a>

Salida en vivo:

Ir a Google (abre en nueva pestaña) Ir a una sección (ejemplo) Enviar Correo (ejemplo)
<strong> y <b>

Función: Ambas etiquetas se utilizan para hacer que el texto se muestre en negrita. La principal diferencia es semántica: <strong> indica que el texto es de "gran importancia" o urgencia, mientras que <b> (bold) solo se utiliza para estilizar texto sin añadir importancia semántica adicional (por ejemplo, para destacar un nombre en un párrafo).

Código:

<p>Este es texto normal, <strong>pero esto es muy importante</strong>.</p>
<p>Aquí un ejemplo de <b>texto solo en negrita</b> sin importancia.</p>

Salida en vivo:

Este es texto normal, pero esto es muy importante.

Aquí un ejemplo de texto solo en negrita sin importancia.

<em> y <i>

Función: Ambas etiquetas se utilizan para hacer que el texto se muestre en cursiva (itálica). Al igual que con <strong> y <b>, la diferencia es semántica: <em> indica "énfasis" (lo que cambia el significado o tono de una frase), mientras que <i> (italic) se usa para texto con una voz o estado de ánimo alternativo (por ejemplo, nombres científicos, títulos de obras, o palabras extranjeras).

Código:

<p>Yo <em>realmente</em> quiero aprender HTML.</p>
<p>El nombre científico es <i>Homo sapiens</i>.</p>

Salida en vivo:

Yo realmente quiero aprender HTML.

El nombre científico es Homo sapiens.

<div>

Función: Un contenedor de bloque genérico. Se usa para agrupar otros elementos HTML y aplicarles estilos CSS o manipularlos con JavaScript. Por defecto, ocupa el ancho completo disponible y coloca el siguiente elemento en una nueva línea.

Código:

<div style="background-color: #e0f7fa; padding: 10px; border-radius: 5px;">
  <p>Este es un párrafo dentro de un div.</p>
  <span>Otro contenido.</span>
</div>
<div style="background-color: #fff3e0; padding: 10px; border-radius: 5px; margin-top: 10px;">
  <p>Este es otro div.</p>
</div>

Salida en vivo:

Contenido del primer Div.

Un span dentro del div.

Contenido del segundo Div.

Los divs son bloques que ocupan su propio espacio vertical y se usan para agrupar.

<span>

Función: Un contenedor en línea genérico. Se usa para aplicar estilos CSS o manipular con JavaScript una pequeña porción de texto o de contenido sin afectar su diseño de bloque. A diferencia de <div>, <span> no introduce un salto de línea.

Código:

<p>Este es un texto con una <span style="color: blue; font-weight: bold;">porción destacada</span> en línea.</p>

Salida en vivo:

Este es un texto con una porción destacada en línea.

<br>

Función: Inserta un salto de línea (line break) dentro de un texto, forzando que el contenido siguiente comience en una nueva línea. Es una etiqueta de autocierre (vacía).

Código:

<p>Primera línea de texto.<br>Segunda línea después de un salto.</p>

Salida en vivo:

Primera línea de texto.
Segunda línea después de un salto.

<hr>

Función: Representa un cambio temático en el contenido o una ruptura a nivel de párrafo, usualmente visualizado como una línea horizontal (horizontal rule). Es una etiqueta de autocierre (vacía).

Código:

<p>Contenido superior.</p>
<hr>
<p>Contenido inferior.</p>

Salida en vivo:

Contenido superior.

Contenido inferior.

<ul> y <li>

Función:

  • <ul>: Define una lista desordenada (Unordered List), donde los elementos se marcan típicamente con viñetas.
  • <li>: Define un elemento de lista (List Item) dentro de una lista (ya sea <ul> o <ol>).

Código:

<ul>
  <li>Elemento de la lista 1</li>
  <li>Elemento de la lista 2</li>
  <li>Elemento de la lista 3</li>
</ul>

Salida en vivo:

  • Elemento de la lista 1
  • Elemento de la lista 2
  • Elemento de la lista 3
<ol> y <li>

Función:

  • <ol>: Define una lista ordenada (Ordered List), donde los elementos se marcan típicamente con números o letras.
  • <li>: Define un elemento de lista (List Item) dentro de una lista (ya sea <ul> o <ol>).

Código:

<ol>
  <li>Primer paso</li>
  <li>Segundo paso</li>
  <li>Tercer paso</li>
</ol>

Salida en vivo:

  1. Primer paso
  2. Segundo paso
  3. Tercer paso
<pre>

Función: Representa texto preformateado. El texto dentro de <pre> se muestra en una fuente monoespaciada, y tanto los espacios como los saltos de línea se respetan (no se ignoran como en el texto normal HTML).

Código:

<pre>
Esta es una línea.
  Esta es otra línea con sangría.
    Y una tercera.
</pre>

Salida en vivo:

Esta es una línea.
  Esta es otra línea con sangría.
    Y una tercera.
<code>

Función: Representa un fragmento de código de programación. El contenido suele mostrarse en una fuente monoespaciada por defecto. A menudo se utiliza dentro de <pre> para bloques de código multilínea.

Código:

<p>La función para imprimir es <code>console.log()</code>.</p>

Salida en vivo:

La función para imprimir es console.log().

<blockquote>

Función: Define una sección que se cita de otra fuente. Los navegadores suelen renderizar el contenido de <blockquote> con sangría.

Código:

<blockquote cite="http://www.ejemplo.com/cita">
  <p>La imaginación es más importante que el conocimiento.</p>
  <footer>— Albert Einstein</footer>
</blockquote>

Salida en vivo:

La imaginación es más importante que el conocimiento.

— Albert Einstein
<q>

Función: Se utiliza para citas cortas en línea. Los navegadores suelen añadir comillas al contenido de <q> automáticamente.

Código:

<p>Sócrates dijo <q>Solo sé que no sé nada</q>.</p>

Salida en vivo:

Sócrates dijo Solo sé que no sé nada.

<abbr>

Función: Representa una abreviatura o un acrónimo. El atributo title puede usarse para proporcionar la descripción completa de la abreviatura, la cual se muestra como un tooltip al pasar el ratón.

Código:

<p>La <abbr title="Organización Mundial de la Salud">OMS</abbr> publicó un informe.</p>

Salida en vivo:

La OMS publicó un informe.

<address>

Función: Proporciona información de contacto para el autor/propietario del documento o de una sección.

Código:

<address>
  Escrito por <a href="mailto:webmaster@example.com">Juan Pérez</a>.<br>
  Visítanos en: Calle Falsa 123, Ciudad.<br>
  Teléfono: +123 456 7890
</address>

Salida en vivo:

Escrito por Juan Pérez.
Visítanos en: Calle Falsa 123, Ciudad.
Teléfono: +123 456 7890
<bdo>

Función: (Bidirectional Override) Se utiliza para anular la dirección del texto actual. El atributo dir (ltr para left-to-right o rtl para right-to-left) es obligatorio.

Código:

<p>Este texto es normal. <bdo dir="rtl">Este texto se leerá de derecha a izquierda.</bdo></p>

Salida en vivo:

Este texto es normal. .izquierda a derecha de leerá se texto Este

<cite>

Función: Se utiliza para definir el título de una obra creativa (por ejemplo, un libro, una canción, una película, una pintura, una escultura, etc.). El contenido de <cite> suele mostrarse en cursiva.

Código:

<p>Como dijo Shakespeare en <cite>Hamlet</cite>.</p>

Salida en vivo:

Como dijo Shakespeare en Hamlet.

<dfn>

Función: Se utiliza para indicar la instancia de definición de un término. El término se suele mostrar en cursiva.

Código:

<p>Un <dfn>algoritmo</dfn> es un conjunto finito de instrucciones o reglas.</p>

Salida en vivo:

Un algoritmo es un conjunto finito de instrucciones o reglas.

<small>

Función: Representa comentarios secundarios y letras pequeñas, como los derechos de autor y el texto legal. El contenido se suele mostrar con una fuente más pequeña.

Código:

<p><small>&copy; 2025 Mi Compañía. Todos los derechos reservados.</small></p>

Salida en vivo:

© 2025 Mi Compañía. Todos los derechos reservados.

<sub> y <sup>

Función:

  • <sub> (subíndice): Define texto en subíndice.
  • <sup> (superíndice): Define texto en superíndice.
Son útiles para fórmulas químicas, expresiones matemáticas, o notas al pie.

Código:

<p>La fórmula del agua es H<sub>2</sub>O.</p>
<p>E = mc<sup>2</sup>.</p>

Salida en vivo:

La fórmula del agua es H2O.

E = mc2.

<ins>

Función: Define texto que ha sido insertado en un documento. Los navegadores suelen subrayar el contenido insertado.

Código:

<p>El precio es <del>$100</del> <ins>$75</ins>.</p>

Salida en vivo:

El precio es $100 $75.

<del>

Función: Define texto que ha sido eliminado de un documento. Los navegadores suelen tachar el contenido eliminado.

Código:

<p>El precio es <del>$100</del> ahora.</p>

Salida en vivo:

El precio es $100 ahora.

<mark>

Función: Define texto que debe ser marcado o resaltado, como si se usara un marcador fluorescente. Se utiliza para indicar relevancia o interés.

Código:

<p>Por favor, <mark>recuerda leer</mark> este párrafo.</p>

Salida en vivo:

Por favor, recuerda leer este párrafo.

<time>

Función: Representa una fecha y/u hora específica. El atributo datetime puede contener la fecha/hora en un formato legible por máquina para herramientas y motores de búsqueda.

Código:

<p>El evento es el <time datetime="2025-12-25">25 de diciembre de 2025</time>.</p>

Salida en vivo:

El evento es el 25 de diciembre de 2025.

Parte 3: Etiquetas de Multimedia y Contenido Embebido

<img>

Función: Inserta una imagen en el documento. Es una etiqueta de autocierre (vacía). Los atributos src (ruta de la imagen) y alt (texto alternativo para accesibilidad) son los más importantes.

Código:

<img src="https://placehold.co/200x120/AEC6CF/white?text=Ejemplo+Imagen" alt="Placeholder de Imagen Cuadrada">

Salida en vivo:

<video>

Función: Incrusta un reproductor de video en el documento. El atributo controls añade los controles de reproducción estándar (pausa, volumen, etc.). Puedes especificar múltiples fuentes con la etiqueta <source> para compatibilidad con diferentes navegadores.

Código:

<video controls width="320" height="240">
  <source src="https://www.w3schools.com/html/mov_bbb.mp4" type="video/mp4">
  Tu navegador no soporta la etiqueta de video.
</video>

Salida en vivo:

<audio>

Función: Incrusta un reproductor de audio en el documento. Similar a <video>, el atributo controls añade los controles de reproducción. También puede usar <source>.

Código:

<audio controls>
  <source src="https://www.w3schools.com/html/horse.mp3" type="audio/mpeg">
  Tu navegador no soporta la etiqueta de audio.
</audio>

Salida en vivo:

<source>

Función: Se utiliza dentro de las etiquetas <video> o <audio> para especificar múltiples archivos de origen de medios. El navegador elegirá el formato que mejor soporte. Esto mejora la compatibilidad.

Código:

<video controls>
  <source src="video.mp4" type="video/mp4">
  <source src="video.ogg" type="video/ogg">
  Tu navegador no soporta el video.
</video>

Salida en vivo:

La etiqueta <source> no tiene una salida visual directa por sí misma, ya que funciona en conjunto con las etiquetas <video> o <audio> para definir las opciones de archivos multimedia.

<iframe>

Función: Incrusta otro documento HTML dentro del documento HTML actual. Esto es útil para incrustar mapas, videos de YouTube, o contenido de otras páginas web.

Código:

<iframe src="https://www.w3schools.com" width="300" height="200" title="Ejemplo de W3Schools"></iframe>

Salida en vivo:

<canvas>

Función: Proporciona un área de dibujo en la página donde se pueden renderizar gráficos, animaciones, juegos o visualizaciones de datos usando JavaScript. Es un "lienzo" en blanco.

Código:

<canvas id="myDrawingCanvas" width="200" height="100" style="border:1px solid #d3d3d3;">
  Tu navegador no soporta canvas.
</canvas>
<script>
  const canvas = document.getElementById('myDrawingCanvas');
  const ctx = canvas.getContext('2d');
  ctx.fillStyle = 'red';
  ctx.fillRect(20, 20, 150, 50); // Dibuja un rectángulo rojo
</script>

Salida en vivo:

Un rectángulo rojo dibujado con JavaScript.

Etiquetas de Tablas

<table>, <thead>, <tbody>, <tfoot>, <tr>, <th>, <td>, <caption>

Función:

  • <table>: El contenedor principal para una tabla de datos.
  • <thead>: Agrupa el contenido de la cabecera de la tabla.
  • <tbody>: Agrupa el contenido principal (filas de datos) de la tabla.
  • <tfoot>: Agrupa el contenido del pie de la tabla (ej. totales).
  • <tr>: Define una fila (Table Row) dentro de la tabla.
  • <th>: Define una celda de encabezado (Table Header). El texto suele estar en negrita y centrado por defecto.
  • <td>: Define una celda de datos (Table Data).
  • <caption>: Proporciona un título o descripción a la tabla, mejorando la accesibilidad.

Código:

<table class="example-table">
  <caption>Datos de Productos</caption>
  <thead>
    <tr>
      <th>Producto</th>
      <th>Precio</th>
      <th>Stock</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Laptop</td>
      <td>$1200</td>
      <td>50</td>
    </tr>
    <tr>
      <td>Mouse</td>
      <td>$25</td>
      <td>200</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="3">Totales aproximados</td>
    </tr>
  </tfoot>
</table>

Salida en vivo:

Datos de Productos
Producto Precio Stock
Laptop $1200 50
Mouse $25 200
Totales aproximados
<colgroup> y <col>

Función:

  • <colgroup>: Se utiliza para agrupar una o más columnas en una tabla para aplicarles un estilo común. Debe ser el primer hijo de un <table>.
  • <col>: Se utiliza dentro de <colgroup> para definir atributos para una o más columnas. El atributo span indica cuántas columnas abarca.
Estas etiquetas son útiles para aplicar estilos a columnas completas de forma declarativa.

Código:

<table class="example-table">
  <colgroup>
    <col span="2" style="background-color:#e0f2fe">
    <col style="background-color:#fff3e0">
  </colgroup>
  <tr>
    <th>Nombre</th>
    <th>Apellido</th>
    <th>Edad</th>
  </tr>
  <tr>
    <td>Ana</td>
    <td>Gómez</td>
    <td>28</td>
  </tr>
</table>

Salida en vivo:

Nombre Apellido Edad
Ana Gómez 28
Luis Pérez 35

Parte 4: Etiquetas de Formularios

<form>

Función: Define un formulario HTML para la entrada del usuario. Los datos dentro del formulario se pueden enviar a un servidor para su procesamiento. Atributos clave: action (URL a donde se envían los datos) y method (método HTTP: GET o POST).

Código:

<form action="/submit-data" method="post">
  <label for="username">Usuario:</label>
  <input type="text" id="username" name="username">
  <br>
  <button type="submit">Enviar</button>
</form>

Salida en vivo:

<input>

Función: Crea varios tipos de campos de entrada de datos, dependiendo del atributo type. Es una de las etiquetas más versátiles en formularios.

Código (ejemplos comunes):

<input type="text" placeholder="Texto">
<input type="password" placeholder="Contraseña">
<input type="number" value="10">
<input type="email" placeholder="correo@ejemplo.com">
<input type="checkbox" checked> Checkbox
<input type="radio" name="opcion" value="1"> Opción 1
<input type="submit" value="Enviar Formulario">
<input type="date">
<input type="color">

Salida en vivo:

<textarea>

Función: Define un área de texto de múltiples líneas. Es útil para entradas de usuario que requieren más espacio, como comentarios o mensajes largos. Los atributos rows y cols especifican el número visible de filas y columnas.

Código:

<textarea rows="4" cols="50" placeholder="Escribe tu comentario aquí..."></textarea>

Salida en vivo:

<button>

Función: Crea un botón clicable. Puede ser de tipo submit (envía el formulario), reset (restablece el formulario) o button (para usar con JavaScript sin enviar/resetear).

Código:

<button type="submit">Enviar Formulario</button>
<button type="button" onclick="alert('Botón JavaScript clicado!')">Hacer Algo</button>

Salida en vivo:

<select> y <option>

Función:

  • <select>: Crea una lista desplegable (menú de selección) donde el usuario puede elegir una o varias opciones.
  • <option>: Define una opción individual dentro de una lista desplegable <select>. El atributo value es el dato que se envía si se selecciona esta opción.

Código:

<select name="frutas">
  <option value="manzana">Manzana</option>

<label>

Función: Define una etiqueta de texto para un elemento de formulario (como <input>, <textarea>, <select>). Al hacer clic en la etiqueta, el control asociado se enfoca. Esto mejora la accesibilidad. Se asocia mediante el atributo for con el id del elemento de formulario.

Código:

<label for="email-field">Correo Electrónico:</label>
<input type="email" id="email-field" name="email">

<fieldset> y <legend>

Función:

  • <fieldset>: Se utiliza para agrupar elementos relacionados en un formulario. Dibuja un recuadro alrededor de los elementos agrupados.
  • <legend>: Proporciona una leyenda (título) para el contenido del <fieldset>.
Estas etiquetas mejoran la estructura semántica y la accesibilidad de los formularios complejos.

<fieldset>
  <legend>Información Personal</legend>
  <label for="nombre">Nombre:</label>
  <input type="text" id="nombre" name="nombre">
  <br>
  <label for="edad">Edad:</label>
  <input type="number" id="edad" name="edad">
</fieldset>

<datalist> y <option>

Función:

  • <datalist>: Contiene una lista de opciones predefinidas para un campo de entrada.
  • <option>: Define una opción dentro de la lista de datos.
Proporciona sugerencias de autocompletado a un campo <input> sin restringir los valores que el usuario puede ingresar. Se conecta a un <input> mediante el atributo list.

Código:

<label for="navegador">Elige un navegador:</label>
<input list="navegadores" id="navegador" name="navegador">
<datalist id="navegadores">

  <option value="Edge">
</datalist>

<output>

Función: Representa el resultado de un cálculo o la acción de un usuario. Es útil para mostrar el resultado de un script de forma dinámica sin recargar la página.

Parte 5: Etiquetas de Scripting

<script>

Función: Se utiliza para incrustar código JavaScript directamente en el documento HTML o para vincular un archivo JavaScript externo. Permite añadir interactividad y lógica dinámica a la página web.

Código (incrustado):

<script>
  console.log("¡Hola desde JavaScript en la consola!");
  // Aquí puedes escribir código JavaScript
</script>

Código (externo):

<script src="ruta/a/mi-script.js"></script>

Salida en vivo:

La etiqueta <script> no tiene una salida visual directa en la página, pero su código JavaScript puede manipular elementos visuales o añadir interactividad (como el botón de animación al final de este documento).

Abre la consola de tu navegador (F12) para ver el mensaje "¡Hola desde JavaScript en la consola!".

<noscript>

Función: Define un contenido alternativo que se muestra si el navegador del usuario no soporta JavaScript, o si JavaScript está deshabilitado en el navegador. Proporciona un mensaje de respaldo.

Código:

<noscript>
  <p>Por favor, habilita JavaScript para ver todo el contenido de esta página.</p>
</noscript>

Salida en vivo:

Dado que JavaScript está habilitado en este entorno, el contenido de <noscript> no es visible.

Etiquetas Semánticas (HTML5)

Estas etiquetas introducidas en HTML5 no solo estructuran el contenido, sino que también le dan un significado contextual o "semántico" al mismo. Esto es crucial para la accesibilidad (lectores de pantalla) y para la optimización de motores de búsqueda (SEO).

<header>

Función: Representa el contenido introductorio o un grupo de elementos de navegación para un documento o una sección. Usualmente contiene encabezados (h1-h6), logotipos, iconos y/o enlaces de navegación (nav).

Código:

<header>
  <h1>Mi Gran Sitio Web</h1>
  <nav>
    <a href="#">Inicio</a> | <a href="#">Contacto</a>
  </nav>
</header>

Salida en vivo:

Mi Sitio Web

Inicio | Acerca

Contenido principal...

<nav>

Función: Representa una sección de un documento que contiene enlaces de navegación principales a otras partes de la página o a otros documentos. Es para bloques de navegación importantes.

Código:

<nav>
  <ul>
    <li><a href="#">Home</a></li>
    <li><a href="#">Productos</a></li>
  </ul>
</nav>

  • Home
  • Servicios
  • Contacto
<main>

Función: Representa el contenido dominante o la funcionalidad central del <body> de un documento. Debe haber solo un elemento <main> en un documento HTML, y su contenido debe ser único y no repetitivo (ej. no incluir barras laterales o pies de página).

Código:

<main>
  <h1>Título del Contenido Principal</h1>
  <p>Este es el contenido más importante y relevante de la página.</p>
</main>

Contenido Principal de la Página

<article>

Destinada a ser distribuible o reutilizable de forma independiente, como una entrada de foro, un artículo de revista o periódico, una entrada de blog, un comentario de usuario, un widget o cualquier otro elemento de contenido independiente.

Código:

<article>
  <h2>Título del Artículo de Blog</h2>
  <p>Este es el contenido de mi artículo.</p>
  <footer>Publicado el 22 de junio de 2025</footer>
</article>

Función: Representa una sección genérica de un documento. Se usa para agrupar contenido relacionado temáticamente. No es un contenedor genérico como <div>; cada <section> generalmente debe tener un encabezado (h1-h6).

<figure> y <figcaption>

Función:

  • <figure>: Representa contenido auto-contenido, como ilustraciones, diagramas, fotos, bloques de código, etc., que se referencia desde el flujo principal del documento, pero que podría ser movido a otro lugar sin afectar el flujo del documento.

<details> y <summary>

Función:

  • <details>: Crea un widget de divulgación a partir del cual el usuario puede obtener o establecer información adicional.
  • <summary>: Proporciona un resumen o título visible para el contenido de <details>. Cuando el usuario hace clic en el resumen, el contenido oculto se expande o colapsa.
Estas son las etiquetas que estoy usando para hacer cada sección colapsable en este mismo documento.

<details>
  <summary>Haz clic para más información</summary>
  <p>Este es el contenido que se oculta/muestra.</p>
</details>
