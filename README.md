# Prototipo-Tienda-Virtual
Prototipo UI/UX para tienda y plataforma de videojuegos (Natlan Studios)  Plataforma web modular e interactiva con navegación dinámico-SPA, sistema de carrito de compras, chat global y modales de autenticación. Construida con HTML5, CSS3, JavaScript (ES6+) y Tailwind CSS.
