# Natlan Studios — Web Gaming & Marketplace Platform

¡Bienvenido al repositorio oficial de **Natlan Studios Platform**! Este proyecto es una interfaz web moderna, responsiva y altamente interactiva diseñada para plataformas de videojuegos, integración de tiendas virtuales (*in-game store*) y gestión de comunidad.

---

## 🚀 Vista Previa & Demostración

- **Demo en Vivo:** https://incandescent-gumption-09f754.netlify.app/
- **Prototipo:** Desarrollo modular dinámico tipo SPA (*Single Page Application*).

---

## ✨ Características Principales

* **Navegación Dinámica (SPA Light):** Transición fluida entre secciones (*Inicio, Juegos, Comunidad, Soporte, Tienda y Perfil*) sin recarga de página.
* **Tienda / E-Commerce Integrado:**
  * Catálogo interactivo categorizado (*Skins, Consumibles, Mejoras, Destacados*).
  * Carrito de compras funcional en tiempo real con contador reactivo y cálculo de totales.
  * Menú navegable adaptativo con dropdown responsivo.
* **Módulos de Comunidad y Chat:**
  * Componente de **Chat Global** responsivo con interfaz personalizada para mensajes.
  * Carruseles dinámicos para imágenes de avances y anuncios.
* **Autenticación y Perfil:**
  * Sistema modal interactivo para Inicio de Sesión y Registro.
  * Vista de perfil de usuario con estadísticas y accesos directos.
* **Diseño Responsivo & Theme Gaming:**
  * Estilizado oscuro (*Dark Mode*) orientado a comunidades de *gaming*.
  * Totalmente adaptable a dispositivos móviles, tablets y escritorio.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Marcado semántico y estructurado.
* **CSS3 Custom & Tailwind CSS:** Estilos avanzados, Flexbox, CSS Grid y componentes dinámicos.
* **JavaScript (ES6+):** Manipulación del DOM, arquitectura de eventos, gestión de estado local para el carrito y control de componentes modulares.
* **FontAwesome & Lucide Icons:** Iconografía moderna para la interfaz de usuario.
